Colección de katas y ejercicios prácticos en **JavaScript** organizados por bloques temáticos y niveles de dificultad. Este proyecto forma parte de la formación en **ASIR (Administración de Sistemas Informáticos en Red)** y tiene como objetivo afianzar los fundamentos del lenguaje, la manipulación del DOM y el uso de características modernas de ES6+.

---

## 📂 Estructura del Proyecto

```
Proyecto2-katas-javascript/
│
├── 📁 ejercicios-basicos-avanzados/   # Lógica, funciones, arrays, objetos
├── 📁 ejercicios-dom/                 # Manipulación del DOM con JS
├── 📁 ejercicios-es6-asincronia/      # ES6+, Promises, async/await
└── 📄 README.md
```

---

## 📚 Contenido por Módulo

### 📌 `ejercicios-basicos-avanzados/`
Ejercicios centrados en los fundamentos y conceptos avanzados de JavaScript:
- Variables, tipos de datos y operadores
- Funciones, closures y scope
- Arrays y métodos funcionales (`map`, `filter`, `reduce`)
- Objetos y prototipos
- Lógica y algoritmia

### 📌 `ejercicios-dom/`
Prácticas de interacción con el Document Object Model del navegador:
- Selección y modificación de elementos HTML
- Gestión de eventos (`addEventListener`)
- Creación y eliminación dinámica de nodos
- Formularios y validación desde JS

### 📌 `ejercicios-es6-asincronia/`
Ejercicios con la sintaxis moderna de JavaScript y programación asíncrona:
- Arrow functions, destructuring y spread operator
- Clases y módulos ES6
- Promesas (`Promise`, `.then()`, `.catch()`)
- `async/await` y manejo de errores asíncronos
- Fetch API y consumo de datos externos

## ▶️ Cómo Usar el Proyecto

### 1. Clonar el repositorio

```bash
git clone https://github.com/diegofonterosa/Proyecto2-katas-javascript.git
cd Proyecto2-katas-javascript
```

### 2. Ejecutar ejercicios con interfaz HTML

Abre el archivo `.html` correspondiente directamente en el navegador:

```bash
# Ejemplo en Linux/macOS
open ejercicios-dom/ejercicio1.html

# O simplemente arrastra el archivo al navegador
```

### 3. Ejecutar scripts con Node.js

```bash
node ejercicios-basicos-avanzados/ejercicio1.js
```
